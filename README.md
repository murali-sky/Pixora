# ✨ Pixora — Every Image Tells a Story

Pixora is a modern, responsive photography gallery built using HTML, CSS, and JavaScript. It showcases beautiful photographs of nature, architecture, and wildlife through an elegant interface with interactive browsing and smooth animations.

## 🌟 Features

- 📱 **Responsive Design** — Adapts to desktops, tablets, and mobile devices.
- 🖼️ **Interactive Image Gallery** — Browse a collection of beautiful photographs.
- 🏷️ **Category Filters** — Filter images by Nature, Architecture, and Animals.
- 🔍 **Lightbox View** — View images in an enlarged overlay.
- ✨ **Smooth Animations** — Enjoy elegant hover effects and transitions.
- 🎨 **Modern UI** — A clean, dark-themed design with elegant typography.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, responsive layout, and animations
- **JavaScript** — Image filtering, lightbox, and navigation
- **Unsplash** — External photography images

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- A code editor such as Visual Studio Code

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd Pixora
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

**Note:** An internet connection is required to load externally hosted images and fonts.
